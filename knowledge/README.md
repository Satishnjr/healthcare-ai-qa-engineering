# Knowledge Directory Index

This directory contains requirements and QA knowledge artifacts for CareFlow Health.

## Purpose of Subdirectories
- `brd/`: Business Requirement Document artifacts (future)
- `prd/`: Product Requirement Document artifacts (future)
- `epics/`: Epic-level requirement decomposition (future)
- `user-stories/`: User stories derived from epics (future)
- `acceptance-criteria/`: Testable acceptance criteria (future)
- `business-rules/`: Product/business validation rules (future)
- `test-scenarios/`: Requirement-aligned test scenario design (future)
- `test-cases/`: Detailed executable test case design (future)

Detailed artifacts will be created in future steps and kept traceable to upstream requirements.
