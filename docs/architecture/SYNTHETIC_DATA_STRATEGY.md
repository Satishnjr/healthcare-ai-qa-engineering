# Synthetic Healthcare Data Strategy

## Data Policy
All data used in CareFlow Health must be synthetic, deterministic where possible, and safe for educational/demo use.

## Example Identifier Patterns
- PAT-10001
- DOC-10001
- APT-10001
- RX-10001
- MR-10001
- INV-10001

## Dataset Categories
- Patients
- Doctors
- Appointments
- Medical records
- Prescriptions
- Insurance
- Billing
- Notifications
- Users

## Prohibited Data
- Real patient names
- Real medical records
- Real phone/address identifiers
- Real insurance identifiers
- Any real PHI
