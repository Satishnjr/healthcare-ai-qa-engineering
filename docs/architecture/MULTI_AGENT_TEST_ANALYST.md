# Multi-Agent Test Analyst

## Purpose
Generate test-case/scenario coverage insights and deterministic regression recommendations.

## Tool Boundary
Primary tools:
- `search_test_cases`
- `get_traceability`
- `search_jira`
- `search_confluence`
- `get_qa_knowledge`

## Output Contract
Test analyst output includes:
- coverage findings
- recommended cases/scenarios
- traceability-linked evidence
