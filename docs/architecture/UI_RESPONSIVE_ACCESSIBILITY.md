# UI Responsive and Accessibility Strategy

## Target Viewports
- Desktop: 1440px, 1280px.
- Tablet: around 768px+.
- Mobile: around 390px+, 375px+.

## Responsive Rules
- Navigation: sidebar on desktop, collapsible/drawer on tablet/mobile.
- Tables: standard table on larger screens, scroll/card fallback on small screens.
- Forms: multi-column to single-column collapse on smaller screens.
- Cards/widgets: adaptive stacking and priority-based ordering.
- Modals: centered desktop, full-width/full-height variants on mobile.

## Accessibility Rules
- Keyboard navigable controls and menus.
- Visible focus indicators and route-change focus placement.
- Semantic HTML landmarks and heading structure.
- Proper labels for all form fields.
- ARIA only when semantics are insufficient.
- WCAG AA contrast target.
- Screen-reader-friendly status/error announcements.

## Browser Coverage
- Chromium, Edge, Firefox, WebKit-equivalent behavior targets.
