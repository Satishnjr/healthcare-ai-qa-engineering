Define a Confluence-like information structure for product, requirements, QA, automation, AI, DevOps, and interview readiness.

## Page Hierarchy Rules
- Space -> Domain Page -> Artifact Page -> Execution/Review Notes.
- Each artifact page links to canonical repository source.
- Superseded pages keep replacement links.
